# 🕵️ ایجنت شکارچی خبر عطر — خلاصه سریع

- هر ۳۰ دقیقه منابع انگلیسی‌زبان (Google News، Bing، Fragrantica، Reddit، YouTube) را **با کمترین فشار به سرورها** می‌گردد.
- موضوعات را بر اساس جنجالی/عجیب/وایرال بودن امتیازدهی می‌کند (شکایت، ممنوعیت، دیسکانتینیود، رکورد فروش، رفتار عجیب، اشتباه برندها، دانستنی‌های باورنکردنی…).
- **آرشیو داخلی** دارد و هرگز مطلب تکراری نمی‌فرستد (حتی اگر همان خبر را رسانه دیگری زده باشد).
- هر روز ساعت **۹:۳۰ به وقت تهران**، **۵ موضوع ناب** را همراه **قلاب، زاویه‌ها و دستور ساخت با موبایل + هوش مصنوعی** به تلگرام شما (`@atr_ads_bot`) می‌فرستد.
- کاملاً رایگان روی **گیت‌هاب اکشنز** اجرا می‌شود؛ نیازی به سرور نیست.

# 🤖 ربات ارسال خودکار پست و ریلز اینستاگرام به کانال تلگرام
### (Instagram to Telegram Auto Forwarder Agent)

این پروژه یک ایجنت هوشمند و خودکار پایتونی است که به‌صورت دوره‌ای پیج اینستاگرام شما را بررسی کرده و به محض انتشار **پست، ریلز (Reels) یا آلبوم‌های چندتایی (Carousel)**، آن‌ها را با کیفیت اصلی دانلود کرده و همراه با کپشن به کانال تلگرام شما ارسال می‌کند.

---

## ✨ ویژگی‌های کلیدی
- **پشتیبانی کامل از انواع مدیا:**
  - 🎬 **ریلز و ویدیوهای تکی:** دانلود با کیفیت بالا و ارسال به تلگرام با قابلیت استریم (`sendVideo`).
  - 📸 **تصاویر تکی:** ارسال با بالاترین رزولوشن (`sendPhoto`).
  - 📚 **پست‌های اسلایدی / آلبومی (Carousel):** ارسال مرتب چند عکس/ویدیو در یک پیام یکپارچه (`sendMediaGroup`).
- **مدیریت هوشمند کپشن:**
  - تلگرام برای مدیا محدودیت ۱۰۲۴ کاراکتر دارد؛ این ربات در صورت طولانی بودن متن، ادامه کپشن را به صورت ریپلای خودکار به همان پیام اضافه می‌کند.
  - درج لینک مستقیم پست اینستاگرام در انتهای پیام (قابل فعال/غیرفعال‌سازی).
- **جلوگیری از ارسال تکراری:**
  - ثبت کد یکتای پست‌ها در فایل `state.json`.
- **۳ روش اجرای انعطاف‌پذیر:**
  - ⚡ **گیت‌هاب اکشنز (GitHub Actions):** بدون نیاز به سرور یا پرداخت هزینه، اجرای اتوماتیک هر ۱۵ دقیقه روی فضای ابری گیت‌هاب!
  - 🐳 **داکر (Docker / Docker Compose):** استقرار آسان و ۲۴/۷ روی سرور لینوکس (VPS).
  - 💻 **اسکریپت مستقیم لوکال / پس‌زمینه (Daemon).**
- **پشتیبانی از سشن و کوکی:** برای جلوگیری از محدودیت‌های موقت اینستاگرام یا دسترسی به پیج‌های خصوصی.

## 📁 ساختار فایل‌های پروژه
```text
├── bot.py                     # هسته اصلی و هماهنگ‌کننده ایجنت

├── config.py                  # مدیریت تنظیمات و خواندن متغیرهای محیطی
├── state.json                 # دیتابیس سبک نگهداری شناسه پست‌های ارسال‌شده
├── requirements.txt           # پیش‌نیازهای پایتونی
├── .env.example               # نمونه فایل تنظیمات متغیرهای محیطی
├── Dockerfile                 # ایمیج داکر برای اجرای سروری
├── docker-compose.yml         # فایل داکر کامپوز برای راه‌اندازی سریع
└── .github/workflows/

```

## 🚀 راهنمای سریع راه‌اندازی

### مرحله ۱: پیش‌نیازهای تلگرام
1. وارد ربات [@BotFather](https://t.me/BotFather) در تلگرام شوید و با دستور `/newbot` یک ربات جدید بسازید. توکن اختصاصی (Token) را کپی کنید.
2. کانال تلگرام خود را بسازید یا باز کنید.
3. ربات خود را به کانال اضافه کرده و دسترسی مدیریت (**Admin**) با مجوز **Post Messages** به آن بدهید.
4. آیدی کانال شما به صورت `@your_channel` خواهد بود (برای کانال‌های خصوصی شناسه عددی با `-100...` شروع می‌شود).

---

### روش اول: اجرای کاملاً رایگان با گیت‌هاب (GitHub Actions)
این روش به سرور نیازی ندارد و هر ۱۵ دقیقه یک‌بار توسط سرورهای ابری گیت‌هاب اجرا می‌شود:
1. فایل‌های پروژه را روی ریپازیتوری گیت‌هاب خود پوش (`git push`) کنید.
2. در گیت‌هاب به مسیر زیر بروید:
   `Settings` > `Secrets and variables` > `Actions` > دکمه `New repository secret`
3. سکرت‌های زیر را وارد کنید:
   - `TELEGRAM_BOT_TOKEN`: توکن بات تلگرام
   - `TELEGRAM_CHAT_ID`: آیدی کانال تلگرام (مثلاً `@my_channel`)
   - `INSTAGRAM_USERNAME`: نام کاربری پیج اینستاگرام (بدون `@`)
4. در مسیر `Settings` > `Actions` > `General` بخش **Workflow permissions** را روی **Read and write permissions** بگذارید و ذخیره کنید (تا بتواند `state.json` را آپدیت کند).
5. از تب **Actions** می‌توانید ورک‌فلو را یک‌بار دستی اجرا کنید یا منتظر بمانید تا طبق زمان‌بندی (هر ۱۵ دقیقه) اجرا شود.

---

### روش دوم: اجرا روی سیستم شخصی یا سرور لینوکس (VPS)

#### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```
*(مطمئن شوید برنامه `ffmpeg` نیز روی سیستم نصب است: `sudo apt install ffmpeg`)*

#### ۲. تنظیم فایل `.env`
فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:
```bash
cp .env.example .env
```
مقادیر `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID` و `INSTAGRAM_USERNAME` را در فایل `.env` وارد کنید.

#### ۳. تست اتصال تلگرام
برای اطمینان از صحت توکن و دسترسی در کانال دستور زیر را اجرا کنید:
```bash
python bot.py --test-telegram
```
پیام تستی به کانال ارسال خواهد شد.

#### ۴. آماده‌سازی اولیه (اختیاری ولی توصیه می‌شود)
اگر نمی‌خواهید پست‌های قدیمی پیج اینستاگرام همگی در کانال فوروارد شوند، با دستور زیر پست‌های فعلی را علامت بزنید:
```bash
python bot.py --init
```

#### ۵. اجرای ربات
- **اجرای مداوم ۲۴ ساعته (Daemon):**
  ```bash
  python bot.py
  ```
- **اجرای یک‌باره (مناسب برای کرون جاب Cron):**
  ```bash
  python bot.py --single-run
  ```

---

### روش سوم: اجرا با داکر (Docker Compose)
اگر سرور شخصی دارید، اجرای داکر ساده‌ترین راه است:
```bash
# تنظیم متغیرها
cp .env.example .env
nano .env

# اجرای پایدار در پس‌زمینه
docker compose up -d --build

# مشاهده لاگ‌ها
docker compose logs -f
```

## 🔒 نکته مهم درباره کوکی و سشن اینستاگرام
اگر پیج اینستاگرام شما خصوصی (Private) است یا سرور شما با محدودیت آی‌پی اینستاگرام روبرو شد:
- می‌توانید با افزونه‌های مرورگر (مانند Get cookies.txt LOCALLY) فایل کوکی اکانت خود را استخراج کرده و با نام `cookies.txt` در کنار پروژه قرار دهید.
- سپس در فایل `.env` خط زیر را فعال کنید:
  ```env
  INSTAGRAM_COOKIES_FILE=cookies.txt
  ```
- بدین ترتیب ربات بدون مشکل محدودیت، پست‌ها و ریلزها را با بالاترین کیفیت دانلود می‌کند.
