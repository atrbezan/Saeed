# 🕵️ ایجنت شکارچی خبر عطر (Perfume News Scout)

ایجنت هوشمندی که **دائم در حال جستجوی محتوای انگلیسی‌زبان دنیای عطر** است و هر روز
**۵ موضوع ناب، جنجالی، عجیب و باورنکردنی** را همراه با **بریف کامل تولید محتوا**
(قلاب، زاویه‌ها، و دستور ساخت با موبایل + هوش مصنوعی) به تلگرام شما می‌فرستد.

---

## ✨ چه چیزهایی پیدا می‌کند؟

| دسته | مثال |
|---|---|
| 🔥 جنجالی / حاشیه | شکایت، رسوایی، بایکوت، دعوای برندها |
| ⛔ ممنوعه / سلامت | ممنوعیت مواد (IFRA)، فراخوان، مناطق بدون عطر |
| 💔 دیسکانتینیود / ریفورموله | حذف یا تغییر فرمول عطرهای محبوب |
| 🤦 اشتباه برندها | کمپین‌های شکست‌خورده، عذرخواهی‌ها |
| 🎭 رفتار عجیب | کارهای عجیب عطرسازها، ریویوورها و بنیان‌گذارها |
| 📈 رکورد و فروش | پرفروش‌ترین‌ها، رکوردها، سولد‌اوت شدن‌ها |
| 🤯 دانستنی باورنکردنی | گران‌ترین/عجیب‌ترین حقایق دنیای عطر |
| 🚀 وایرال | عطرهایی که تیک‌تاک و اینستاگرام را منفجر کرده‌اند |
| 🎭 دوپ و کپی | جنگ کپی‌ها و شباهت‌های جنجالی |
| ⭐ سلبریتی | عطرهای سلبریتی‌ها و حواشی‌شان |

## 🧠 منابع (همه رایگان، بدون هیچ کلید API)

- **Google News RSS** — ۸ جستجوی هدفمند روی کلمات جنجالی (شکایت، ممنوعیت، رکورد فروش، …)
- **Bing News RSS** — پوشش خبری مکمل
- **Fragrantica News** — اخبار مرجع دنیای عطر (RSS غیررسمی آپدیت روزانه)
- **Reddit** — r/fragrance (نبض جامعه عطربازها)
- **YouTube** — کانال‌های بزرگ عطر (برای شکار رفتارهای عجیب و وایرال)

> منابع در فایل `scout_sources.py` تعریف شده‌اند؛ به‌سادگی می‌توانید منبع یا
> کوئری جدید اضافه کنید.

## 🛡 امکانات کلیدی که خواسته بودید

1. **آرشیو داخلی ضدتکرار** — هر خبر با هش لینک + «اثر انگشت تیتر» در
   `scout_state.json` ثبت می‌شود. حتی اگر همان خبر را رسانه دیگری منتشر کند
   (تیتر مشابه) تشخیص داده شده و **هرگز تکراری ارسال نمی‌شود**.
2. **جستجوی دائمی بدون فشار به سرورها** — هر منبع بازه زمانی مخصوص خودش را دارد
   (۱.۵ تا ۴ ساعت)، بین درخواست‌ها ۲ تا ۵ ثانیه تأخیر تصادفی می‌افتد، و اگر منبعی
   خطا بدهد به‌صورت نمایی (تا ۱۶ برابر) عقب‌نشینی می‌کند. منابعی که خبر جدید ندارند
   خودکار کم‌تر چک می‌شوند.
3. **هر روز دقیقاً ۵ موضوع** — اگر در یک روز خبر قویِ کافی پیدا نشود، از بانک
   «دانستنی‌های همیشه‌سبز» (حقایق واقعی و تأییدشده در `scout_evergreen.py`)
   پر می‌شود. این دانستنی‌ها هم فقط یک‌بار مصرف می‌شوند.
4. **بریف ساخت محتوا** — هر موضوع با: قلاب ۳ ثانیه اول، دلیل وایرال شدن،
   ۳ زاویه پیشنهادی، دستور ساخت گام‌به‌گام با **دوربین موبایل + صدای خودتان +
   تصاویر هوش مصنوعی + ادیت**، لینک منبع و هشتگ‌های فارسی ارسال می‌شود.
5. **بدون نیاز به سرور** — روی همان **گیت‌هاب اکشنز رایگان** ریپازیتوری اجرا می‌شود.

## 🚀 راه‌اندازی (۱۰ دقیقه)

### مرحله ۱: تلگرام
ربات شما (`@atr_ads_bot`) باید یک **توکن** داشته باشد:
1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید.
2. اگر ربات را قبلاً ساخته‌اید: `/mybots` → انتخاب `@atr_ads_bot` → **API Token** را کپی کنید.
3. برای پیدا کردن `chat_id` خودتان: ربات را در تلگرام باز کنید، دکمه **Start**
   (یا `/start`) را بزنید، سپس روی سیستمی که پایتون دارد اجرا کنید:
   ```bash
   python scout.py --whoami
   ```
   آیدی عددی چت شما نمایش داده می‌شود. (اگر می‌خواهید به **کانال** بفرستد، ربات را
   ادمین کانال کنید و به‌جای عدد، `@نام‌کانال` را استفاده کنید.)

### مرحله ۲: گیت‌هاب اکشنز (رایگان، بدون سرور)
1. کد را پوش کنید (همین ریپازیتوری).
2. در گیت‌هاب: `Settings` → `Secrets and variables` → `Actions`:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات
   - `TELEGRAM_CHAT_ID` = آیدی چت/کانال
   - (اختیاری) در تب `Variables`: `SCOUT_DIGEST_HOUR=9` و `SCOUT_DIGEST_MINUTE=30`
3. تمام! ورکفلوی **Perfume News Scout** هر ۳۰ دقیقه آرشیو را به‌روز می‌کند و هر روز
   ساعت **۹:۳۰ به وقت تهران** دایجست ۵ تایی را به تلگرام شما می‌فرستد.
   آرشیو (`scout_state.json`) خودکار به ریپازیتوری کامیت می‌شود تا هیچ‌وقت تکراری نفرستد.

> اگر فعلاً تلگرام را تنظیم نکرده‌اید، ایجنت باز هم به جمع‌آوری آرشیو ادامه می‌دهد؛
> بعد از تنظیم، اولین دایجست ارسال می‌شود.

### تست سریع
در تب `Actions` گیت‌هاب، ورکفلوی `Perfume News Scout` را با دکمه
**Run workflow** به حالت `digest` اجرا کنید تا همین الان یک دایجست بگیرید.

## 💻 اجرا روی سیستم خودتان (اختیاری)

```bash
pip install -r requirements.txt
cp .env.example .env       # توکن و آیدی را وارد کنید

python scout.py --test-telegram   # تست اتصال تلگرام
python scout.py --whoami          # پیدا کردن chat_id
python scout.py --preview         # ساخت و نمایش دایجست بدون ارسال
python scout.py --digest-now      # ارسال فوری دایجست امروز
python scout.py                   # اجرای دائمی (هر ۳۰ دقیقه جستجو)
```

روی **ترموکس اندروید** یا **راسپری پای** هم با همین دستورها کار می‌کند — فقط پایتون
و `pip install requests python-dotenv` لازم است.

## ⚙️ شخصی‌سازی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `SCOUT_DIGEST_HOUR` / `SCOUT_DIGEST_MINUTE` | `9` / `30` | ساعت ارسال روزانه به وقت تهران |
| `SCOUT_MIN_SCORE` | `25` | حداقل امتیاز یک خبر برای انتخاب (بالاتر = سخت‌گیرتر) |
| `SCOUT_MAX_FEEDS` | `6` | تعداد منبع در هر دور اجرا |
| `SCOUT_POLL_MINUTES` | `30` | فاصله دورهای جستجو در حالت دائمی |
| `SCOUT_LLM_API_KEY` | — | (اختیاری) برای نگارش حرفه‌ای‌تر بریف‌ها با هوش مصنوعی |
| `SCOUT_LLM_BASE_URL` / `SCOUT_LLM_MODEL` | OpenAI / `gpt-4o-mini` | هر سرویس سازگار با OpenAI |

**افزودن منبع/کوئری جدید:** فایل `scout_sources.py` — یک خط به لیست
`GOOGLE_QUERIES` یا `YOUTUBE_CHANNELS` اضافه کنید.
**افزودن دانستنی همیشه‌سبز:** فایل `scout_evergreen.py`.

## 📁 فایل‌های ایجنت

```
├── scout.py               # هسته اصلی: جستجو، امتیازدهی، انتخاب و ارسال دایجست
├── scout_sources.py       # تعریف منابع خبری
├── scout_scorer.py        # موتور امتیازدهی و دسته‌بندی موضوعات
├── scout_archive.py       # آرشیو و حذف تکراری‌ها
├── scout_briefs.py        # تولید بریف فارسی تولید محتوا (+ اتصال اختیاری LLM)
├── scout_evergreen.py     # بانک دانستنی‌های واقعی همیشه‌سبز
├── scout_telegram.py      # ارسال به تلگرام
├── scout_state.json       # آرشیو (خودکار توسط گیت‌هاب اکشنز به‌روز می‌شود)
└── .github/workflows/scout.yml  # اجرای رایگان هر ۳۰ دقیقه
```
